How scoring works

Completion 40 · Reliability 25 · Speed 20 · Experience 15 = 100. Grades: A ≥ 80, B ≥ 60, C ≥ 40, else D. No history → “insufficient data”, never a fabricated score.

Data: AgentEscrow v1 + v2 events on QDay Aevum testnet (chain 44005), plus live escrowOf() state per escrow. Scoring policy can be sealed in a Terminal 3 TEE contract — see the repo README.
